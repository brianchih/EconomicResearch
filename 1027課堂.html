AI 學術文獻檢索指南與各組實證進度診斷

Google AI Studio API 串接、文獻檢索策略、論文速讀與專題實證進度控管

API 申請 Google AI Studio API Key 申請與講義串接指南

為了調用最新的 Gemini AI 模型幫我們自動擴充與發想學術關鍵字，必須取得個人的 API 通關金鑰（API Key）。

🔑 API Key 申請四步驟

  1. 登入 Google AI Studio 官網並選擇個人的 Google 帳號。
  2. 點擊左下角 🔑 Get API key。
  3. 點選右上角 Create API key（可填寫用途名稱如：文獻搜尋）。
  4. 複製產生的 API Key 字串（注意保密，勿外洩）。

⚙️ 講義網頁設定與 AI Studio Build 應用

  • 回到講義右上角，點選未設定 API（紅色圖示），貼上金鑰後儲存，燈號變為綠色即可運作。
  • 在 Google AI Studio 點擊 New App / 新增應用程式，可用 Prompt 直接描述需求，AI 將在幾分鐘內自動建構具備 GUI 介面的分析網頁。

檢索架構 因果關係邏輯 ($X \rightarrow Y$) 與 5 大主流學術資料庫

🎯 確定研究主題與變數對應

確立主題因果對應：$X$（自變數 / 因）$\rightarrow$ $Y$（依變數 / 果），並加入控制變數（如總體大環境利息、通膨、房價等）。
範例：最低工資提高 ($X$) 對青年失業率 ($Y$) 之影響 — 使用雙重差分法 (DID)。

📚 5 大推薦主流學術資料庫

1. Google Scholar

學術搜尋引擎首選，用於快速檢索國內外真實文獻與引用次數。

2. SSRN

社會科學研究網絡，收錄最新的經濟與金融工作論文 (Working Papers)。

3. NBER

美國經濟研究所，獲得國際頂級經濟學者最新進行中研究報告。

4. 華藝線上圖書館

國內學術期刊與會議論文最齊全之中文文獻資料庫。

5. 臺灣博碩士論文

國家圖書館維護，提供精準與模糊檢索國內碩博士學位論文。

文獻閱讀 AI PDF 速讀篩選與「AI 幻覺」避坑指引

💡 使用 AI (Gemini/Claude) 快速剖析 PDF

  1. 將從資料庫下載之真實 PDF 論文直接上傳至 AI。
  2. 提示 AI 提煉：研究動機、使用資料庫/樣本期間、計量模型、核心研究結論與對本研究的啟示。
  3. 彙整各篇發現，製作文獻綜述總表。

⚠️ 嚴防「AI 幻覺（Hallucination）」捏造論文

AI 自動生成的文獻清單常出現虛構的作者、期刊或不存在的年份（如虛構鄭秀玲 2015 論文）。
鐵律：AI 僅能用於發想「關鍵字與變數」，搜尋到的論文必須親自到 Google Scholar 或臺灣博碩士論文網驗證真偽並下載原文。

小組診斷 今日各組實證進度點名與關鍵卡關問題

第九組：房價與生育率關聯性分析

現況與卡關：目前僅有家庭收支調查與總體房價/生育率，資料維度不足。

老師指導：僅看總體資料不夠，需加入 SRDA「家庭動態調查」或「社會變遷基本調查」等個體微觀資料。

第十一組：國際原油價格對台灣油品產業（中油/台塑）影響

現況與卡關：Arimos 找不到原油數據，改自 Yahoo 財經抓取原油價格。

老師指導：光有原油價格 (因) 不夠，必須抓齊台塑與中油的個體/產業數據 (果)，若資料始終無法串齊應果斷換題目。

第四組：油價波動與民生物價關聯

現況與卡關：題目調整為油價對物價影響，卡在物價指數資料頻率與期間長短。

老師指導：資料品質至少需達到「月資料」，季資料或年資料過於粗糙無法進行有效實證檢定。

第八組：便利商店產業市場結構、競爭策略與經營績效

現況與卡關：研究主題較廣，不易直接找到對應資料。

老師指導：拆解依變數 $Y$（經營績效：效率、市占率、獲利）與自變數 $X$（市場結構、進入障礙、定價策略），至 Google Scholar 篩選同業個案文獻。

第六組：經濟與社會因素對薪資變動之影響

現況與卡關：擬採用線性迴歸，但樣本僅有 2 年月資料（約 24 筆），解釋變數過多。

老師指導：自由度不足危機！估計 24 個變數不可能僅用 24 筆樣本，必須將時間軸拉長，抓取更多年份之月資料。

第五組（美台利差與資本市場）& 第一組（題目未定）

第五組指導：美台利差涉及聯準會政策與匯率，須串接月資料或日資料之資本市場數據，不可僅停留在理論描述。

第一組與未定題目小組：時間僅剩 3 週！請立即至「金融雙豐前瞻研究競賽」專區挑選現成主題與聯徵中心開放資料並儘快報名。

🚨 課後強制作業要求（三週後即將交報告）：

請各小組加速進度，下次課堂須提出「整理完成的資料集檔案」，明確標示：

  • 變數清單（標明 $X, Y$ 及控制變數）。
  • 資料頻率（日 / 月 / 季）與時間區間（例如：2010–2025 年）。
  • 資料型態（個體 Microdata 或總體 Macrodata）與原始資料庫來源。
  • 已蒐集之關鍵學術文獻清單及目前初步發現之實證現象與創新突破點。
