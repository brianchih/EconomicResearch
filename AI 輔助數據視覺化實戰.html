☁️ 一、 為什麼選擇 Google Colab？

過去進行資料分析時，常卡在環境安裝、套件衝突與電腦效能不足。Google Colab（Collaboratory）解決了這些痛點：

1. 完全免安裝環境

只需要一個 Google 帳號，開啟瀏覽器即可直接執行 Python 程式碼，免去繁瑣的系統設定。

2. 免費超級電腦算力

Google 免費借出雲端高效能主機與 GPU 資源，處理幾十萬筆大規模資料依然流暢迅速。

3. 內建 Gemini AI 助手

介面右側直接整合 Gemini AI 助手，可以用中文輸入提示詞（Prompt）讓 AI 自動寫出寫碼與 Debug。

⚠️ 重要提醒（雲端暫存與額度管理）：
1. 檔案暫存性： 上傳至 Colab 左側工作區的檔案僅於當次執行階段有效，關閉頁面後會被刪除，個人電腦務必保留原始檔。
2. AI 每日算力額度： 免費版 AI 額度有限，建議小組成員分工合作、避免多人同時對同一問題重複送出 prompt，以節省算力。

🔤 二、 關鍵突破：修復 Matplotlib 中文顯示亂碼（方框）

由於 Python 的預設繪圖套件（Matplotlib）沒有內建中文字型，繪製圖表標籤時常會出現方框亂碼（如 □□□）。

通用修復方案：在 Colab 安裝「文泉驛正黑」中文字型

在你的 Colab 筆記本第一個區塊（Code Cell）貼上並執行以下程式碼，即可一鍵徹底解決中文字體亂碼：

# 1. 安裝中文字型套件 !apt-get install -y fonts-wqy-zenhei # 2. 設定 Matplotlib 使用文泉驛正黑中文字型 import matplotlib.pyplot as plt import matplotlib as mpl plt.rc('font', family='WenQuanYi Zen Hei') mpl.rcParams['axes.unicode_minus'] = False # 解決負號 '-' 顯示為方框的問題 print("✨ 中文字型設定完成！現在圖表可以正常顯示中文標籤囉。")

📈 三、 三大資料庫視覺化分析實戰範例

1. AREMOS 總體經濟：CPI 物價指數 vs. 受僱薪資（雙 Y 軸時間序列圖）

研究目的： 觀察過去 20 年全台物價上漲速度是否高於薪資成長幅度。

🤖 搭配 Gemini AI 的提示詞 (Prompt) 範例：
「我上傳了一個 Excel 檔案（檔名：AREMOS_data.xlsx），包含了日期 (Date)、物價指數 (CPI) 與每人每月平均薪資 (Wage)。請幫我寫 Python 程式，繪製包含左右雙 Y 軸的時間序列折線圖，並確保中文標籤顯示正常。」
import pandas as pd import matplotlib.pyplot as plt # 讀取 AREMOS 整理好的 Excel 檔 df = pd.read_excel('AREMOS_data.xlsx') # 繪製左右雙 Y 軸圖表 fig, ax1 = plt.subplots(figsize=(10, 5)) # 左 Y 軸：物價指數 CPI color = 'tab:red' ax1.set_xlabel('時間（年月）') ax1.set_ylabel('消費者物價指數 (CPI)', color=color) ax1.plot(df['Date'], df['CPI'], color=color, linewidth=2, label='CPI 物價指數') ax1.tick_params(axis='y', labelcolor=color) # 右 Y 軸：平均薪資 ax2 = ax1.twinx() color = 'tab:blue' ax2.set_ylabel('每人每月平均薪資 (元)', color=color) ax2.plot(df['Date'], df['Wage'], color=color, linewidth=2, linestyle='--', label='平均薪資') ax2.tick_params(axis='y', labelcolor=color) plt.title('台灣物價指數 (CPI) 與每人每月平均薪資趨勢對比 (雙 Y 軸)') fig.tight_layout() plt.grid(True, linestyle=':', alpha=0.6) plt.show()

2. SRDA 家庭動態調查 (PSFD)：居住狀態 vs. 幸福感（散佈圖與箱形圖）

研究目的： 探討成年子女「與父母同住」或「搬離獨居」對生活滿意度分數（1~7分）的分布差異。

import pandas as pd import seaborn as sns import matplotlib.pyplot as plt # 讀取轉檔後的 SRDA 個體問卷 CSV 檔 df = pd.read_csv('converted_data.csv') # 繪製箱形圖 (Boxplot) 比較兩組幸福感分布 plt.figure(figsize=(8, 5)) sns.boxplot(x='居住狀態', y='生活幸福感', data=df, palette='Set2') plt.title('SRDA 家庭動態調查：與父母同住 vs. 獨居青年之幸福感分布比較') plt.xlabel('居住狀態 (1:同住, 2:獨居)') plt.ylabel('生活幸福感評分 (1:極不快樂 ~ 7:極快樂)') plt.grid(axis='y', linestyle='--', alpha=0.7) plt.show()

3. 政府開放資料 (data.gov.tw)：多月份交通事故 CSV 自動合併與趨勢

研究目的： 自動讀取資料夾中 12 個月份的事故 CSV 檔，合併後計算月度變化。

import glob import pandas as pd import matplotlib.pyplot as plt # 1. 自動搜尋資料夾中所有符合命名規律的 CSV 檔案 file_list = glob.glob('traffic_data_*.csv') # 2. 批次讀取並合併為一個大型 Dataframe df_list = [pd.read_csv(file) for file in file_list] merged_df = pd.concat(df_list, ignore_index=True) # 3. 按月份統計交通事故總件數 monthly_counts = merged_df.groupby('月份').size() # 4. 繪製長條圖 plt.figure(figsize=(9, 4.5)) monthly_counts.plot(kind='bar', color='skyblue', edgecolor='black') plt.title('全台交通事故月度件數統計趨勢圖') plt.xlabel('月份') plt.ylabel('事故總件數') plt.xticks(rotation=0) plt.grid(axis='y', linestyle=':', alpha=0.7) plt.show()
