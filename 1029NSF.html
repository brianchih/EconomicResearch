國科會研究計畫：美妃研究進度與家庭結構變遷討論總彙整

結合《家庭收支調查》(FiES) 與《台灣家庭動態資料庫》(PSFD) 微觀資料分析

美妃專案進度與會議討論重點記錄

進度核心摘要： 團隊已成功運用 FiES 追蹤家庭「學生身份」與「教育支出」佔比；同時完成 PSFD CI2000（子代追蹤樣本）編碼簿的摸底，下一步將建立「單一受訪者最長生命歷程追蹤」與 ABM 模型代理人（Agent）設定。

一、 家庭收支調查 (FiES) 數據觀察

  • 核心家庭學生比例下滑：核心家庭中「有學生身份成員」的比例逐年降低，主要反映出子女成長畢業進入職場，以及「無子女夫婦二人戶」佔比上升。
  • 三代同堂托育支持強韌：三代同堂家戶中，長年穩定有高達約 60% 的家庭含有在學學生，驗證了台灣祖父母提供後勤托育支持的普遍性。
  • 教育支出佔比低於預期：全台平均教育支出佔家庭收入比例多落在 10% 以下，主因是台灣公立學校（國中小至高中）學費極低，拉低了整體平均；但若就讀私立學校（一學期達 15 萬元），對個別家庭負擔極沉重。
  • 收支結構穩定性：家庭消費最大宗為「住宅服務/水電瓦斯（約 25%）」與「食品餐飲（約 18%）」，兩者即佔去可支配所得的近半數。

二、 台灣家庭動態資料庫 (PSFD) 資料庫摸底進度

  • CI2000 子代樣本解析：CI2000 為 1999 年首批主樣本（`RI1999`）長大滿 18/20 歲的子女世代，2000 年基期共 1,379 人（約 1980 年/69 年次出生）。
  • 貫時性問卷覆蓋：包含公私立求學、才藝補習、家教、課外留學、家庭與同儕關係（約 1/4 回答常與父母吵架）及婚育意願等變數。

三、 後續任務規劃 (Next Steps)

  1. 最長生命歷程追蹤：從 1999 年的原始 ID 中，找出被追蹤波次最多、歷程最完整的個體，還原 20 多年來的家戶演變故事。
  2. 計算 ABM 轉移機率：運用 `CI2000` 連續波次，計算代理人求學結束後的「分家、結婚、獨居、與父母同住」條件機率。

台灣家庭結構 30 年實證發現 (1995–2024)

基於主計總處家庭收支調查（FiES）全台微觀加權推估之真實數據：

1. 核心家庭（Nuclear）加速萎縮

由父母與未婚子女組成的標準核心家庭，占比從 1995 年的 53.31% 降至 2024 年的 31.82%，不再佔全台家戶的絕對多數。

2. 夫婦二人戶（Couple）翻倍爆發

無子女同住之夫婦二人戶（含頂客族 DINK 與空巢期中老年夫婦）由 1995 年的 10.48% 翻倍成長至 2024 年的 21.84%。

3. 女戶長單人戶（Single-F）顯著成長

女戶長單人戶從 1999 年約 32 萬戶一路爆發至 2024 年超過 84 萬戶，顯著超越男戶長（約 60 萬戶），反映女性平均餘命較長（高齡喪偶獨居）與高學歷女性經濟獨立單身趨勢。

4. 單親家庭高度集中於女性戶長

女性戶長單親家庭長期維持在 25–30 萬戶，為男性單親戶（8–13 萬戶）的 2.5 至 3 倍，顯示離異或喪偶後未成年子女照顧責任依然高度傾斜於母親。

5. 「其他複合家庭」成為新型態緩衝墊

包含未婚手足共居、旁系親屬同住與非婚夥伴合租的「其他複合家庭」，總戶數爆發至近 90 萬戶，成為高房價下的彈性居住策略。

PSFD 最長歷程追蹤程式邏輯示範 (Python)

import pandas as pd

def track_longest_individual_history(psfd_years_dict, target_id):
    """
    從 PSFD 歷年資料庫中串接單一受訪者 (target_id) 的貫時性家庭與婚育歷程
    """
    history = []
    for year, df in psfd_years_dict.items():
        if target_id in df['id'].values:
            person = df[df['id'] == target_id].iloc[0]
            history.append({
                'year': year,
                'age': person.get('age'),
                'marital_status': person.get('marriage'),
                'household_type': person.get('h_type'),
                'num_children': person.get('n_child')
            })
    return pd.DataFrame(history)
