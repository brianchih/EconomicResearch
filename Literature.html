一、 為什麼我們需要 API Key？

本課程利用 Google Gemini API 來協助拆解研究題目中的 個體/總體變數 ($X \rightarrow Y$)，並發想頂刊（如 AER, QJE, NBER）常用的 英文經濟學專業術語 與 計量模型關鍵詞（DID, IV, RDD 等）。金鑰僅會儲存於您的個人瀏覽器端，安全性高。

二、 3 分鐘快速申辦步驟 (免費版 Free Tier)

  1. 前往 Google AI Studio 官網。
  2. 登入您的 Google 帳號並同意條款。
  3. 點擊左上角的 Get API key 按鈕。
  4. 點擊 Create API key，選取新的專案生成金鑰。
  5. 複製以 AIzaSy... 開頭的字串，並貼入本網頁右上角的 API 設定按鈕中。

三、 資安與費用規範

  • 完全免費：Google Free Tier 提供每分鐘最多 15 次請求，課堂演練完全不收費也不需綁定信用卡。
  • 金鑰安全：API Key 等同於您的個人密碼，請勿公開傳給他人或上傳至公開 GitHub 專案。
