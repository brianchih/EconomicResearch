📊 二、 比賽指定 8 大高品質實證資料庫

不用煩惱找不到資料！大會一次提供 8 大涵蓋社會、家庭、心理、政治與媒體的高品質次級資料庫：

1. 家庭動態調查 (PSFD) 長期追蹤婚姻、生育、搬家、與父母同住及生活滿意度。
2. 臺灣社會變遷基本調查 (TSCS) 涵蓋社會階層、文化價值觀、工作與家庭態度變遷。
3. 臺灣數位世代青少年追蹤 (TIGPS) 關注 Z 世代網路使用、心理成長與行為發展。
4. 台灣選舉與民主化調查 (TEDS) 政治參與、投票行為、公共議題與民主態度數據。
5. 亞洲民主動態調查台灣區 (ABS) 跨國民主品質、政治文化與社會信任比較。
6. 臺灣幼兒發展調查資料庫 (KIT) 早期幼兒發展、托育環境與家庭教育追蹤。
7. 臺灣傳播調查資料庫 (TCS) 媒體使用、網路社交、娛樂、健康與日常生活。
8. 臺灣法律與社會變遷調查 民眾法治觀念、法律行為與社會制度意識。
💡 實例啟發：家庭動態調查 (PSFD) 熱門研究話題
* 「成年後搬出去住比較自由，還是住家裡比較舒服？」
* 「跟父母同住的生活滿意度真的比較低嗎？」
學者運用 PSFD 追蹤數據發現：統計上「住家裡」或「搬出去」的幸福感沒有顯著差異，真正造成心情起伏的是「搬家這件事帶來的適應壓力」！這樣的題目既接地氣又具備學術嚴謹度。

💻 三、 SRDA 資料下載與 Python 轉檔實作

1. 資料庫申請與解壓縮結構

至 SRDA 官網 註冊帳號並申請資料集（如 PSFD `RR2022` 或 `RR2024`）。下載解壓後包含：

  • 資料使用說明 (PDF/Word)： 解釋計畫背景與抽樣方法。
  • 訪員問卷檔： 查看題號（如 A07 生活快樂程度 1-7 分、A10 生活滿意度、平均月收入等）。
  • 編碼簿 (Codebook)： 記載變數名稱與選項代碼（如 66 代表不知道、77 代表其他、88 代表拒答）。
  • 數據資料檔： 包含 `.sav` (SPSS)、`.dta` (Stata) 與 `.csv` 格式。

2. 用 Python (Pandas/pyreadstat) 自動讀取與轉換 `.sav` 檔

若下載到的資料集為 SPSS 的 `.sav` 檔，可直接在 Google Colab 貼上以下程式碼轉為 `.csv` 檔：

# 1. 安裝讀取 SPSS 檔案所需的套件 !pip install pyreadstat pandas import pandas as pd import pyreadstat # 2. 上傳並讀取 .sav 數據檔與標籤資訊 file_path = 'RR2022.sav' # 請替換為您上傳的 .sav 檔名 df, meta = pyreadstat.read_sav(file_path) # 3. 檢視前 5 筆資料與變數名稱 print("資料維度：", df.shape) print(df.head()) # 4. 匯出為 CSV 檔案（包含中文字型支援） df.to_csv('converted_data.csv', index=False, encoding='utf-8-sig') print("✨ 檔案已成功轉換為 converted_data.csv！")
