💡 協助第 02 組突破與定題的深層引導問題

導師教學指引

一、從「工具學習」跨越至「核心命題確立」（擺脫未定狀態）

  • 研究主題定位與發想：小組目前已學會 RStudio 與 SRDA/AREMOS 讀檔，但題目仍標示為「未定」。小組更偏向研究「總體經濟（如通膨與利率對投資之影響）」還是「個體/產業面（如金融科技、永續消費或房價負擔）」？
  • 資料庫確定 (Data Source Commitment)：如果打算使用 RStudio 或 Python，是否能在本週確定主要使用的資料集（例如：SRDA 家庭收支調查、AREMOS 總經年報或政府實價登登錄檔）？

二、工具整合與分析深化（RStudio + Python / AI 雙軌應用）

  • R 與 Python 之協同分工：謝佳恩已掌握 RStudio，陳奇揚善用 AI 生成程式碼。小組能否建立一套流程，由 RStudio 負責前置資料清理與敘述統計，再由 Colab / Python 產出迴歸散佈圖與計量模型？
  • 相關性與迴歸驗證：下載資料後，小組能否在下週產出第一張含有趨勢線與相關係數的散佈圖，並試著解釋其經濟邏輯？

三、團隊定位與競賽目標對接

  • 團隊分工與固定會議機制：經歷過成員流動後，第 02 組目前的成員架構已趨穩定。小組是否已確立每週固定開會時間與進度檢核點？
  • 競賽對接方向建議：
    • 若選擇「總體金融與經濟波動」，可對接《金融研訓院 前瞻金融研究競賽》。
    • 若選擇「個體調查與社會經濟」，極適合投稿《臺灣經驗實證調查資料論文獎》。
