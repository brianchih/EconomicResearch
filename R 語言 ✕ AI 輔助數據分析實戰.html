第 3 步：開啟 RStudio 開工！

💡 RStudio 介面四大區塊導覽：
1. 左上（Script）： 撰寫程式碼與儲存 `.R` 檔的地方。
2. 左下（Console）： 程式碼執行區與輸出結果顯示區。
3. 右上（Environment）： 查看載入的資料集 (Dataframe) 與變數。
4. 右下（Files / Plots）： 查看專案檔案、套件安裝狀態與繪製出來的圖表。

📊 三、 三大資料庫 R 語言實務處理與統計分析

1. 政府開放資料 (data.gov.tw)：自動化讀取與合併多個 CSV 檔

情境： 下載了 12 個月份的全台交通事故 CSV 檔案，使用 R 語言多檔合併套件一次處理。

# 1. 安裝與載入基礎資料處理套件 if(!require(tidyverse)) install.packages("tidyverse") library(tidyverse) # 2. 設定資料夾路徑與搜尋符合規律的 CSV 檔案 file_folder <- "C:/R_data/monthly_traffic/" file_list <- list.files(path = file_folder, pattern = "^traffic_2023_.*\\.csv$", full.names = TRUE) # 3. 批次讀取並自動合併為一個完整的 data frame merged_data <- file_list %>% map_dfr(read_csv) # 4. 查看合併後的資料總筆數與前幾筆資料 glimpse(merged_data) head(merged_data)

2. SRDA 個體問卷：讀取 `.sav` 檔與卡方檢定 (Chi-Square Test)

情境： 讀取 SRDA 家庭動態調查 (PSFD) 的 SPSS `.sav` 檔，分析「居住狀態（同住/獨居）」與「居住滿意度（滿意/不滿意）」是否互相獨立。

# 1. 載入讀取 SPSS 檔案所需的 haven 套件 if(!require(haven)) install.packages("haven") library(haven) # 2. 讀取 SRDA 下載的 .sav 數據檔 psfd_data <- read_sav("RR2022.sav") # 3. 建立交叉次數表 (Contingency Table) contingency_table <- table(psfd_data$居住狀態, psfd_data$居住滿意度) print(contingency_table) # 4. 執行卡方獨立性檢定 chisq_result <- chisq.test(contingency_table) print(chisq_result) # 5. 解讀結果：若 p-value <= 0.05，代表居住狀態與滿意度有顯著相關！

3. AREMOS 總體經濟與政策分析：單因子變異數分析 (ANOVA)

情境： 比較「北部、中部、南部」三大區域在政府推動區域平衡政策後，平均薪資成長率是否有顯著差異。

# 1. 執行單因子變異數分析 (ANOVA) anova_model <- aov(薪資成長率 ~ 區域, data = aremos_region_data) # 2. 顯示 ANOVA 摘要表 summary(anova_model) # 3. 若 Pr(>F) <= 0.05 代表有顯著差異，進一步執行 Tukey 事後檢定 (Post-Hoc Test) TukeyHSD(anova_model)

🛠️ 四、 R 語言常見錯誤與 AI 排錯 SOP

常見錯誤 1：缺少套件 (No Package Found)
Error in library(tidyverse) : there is no package called ‘tidyverse’
👉 解法： 執行 install.packages("tidyverse") 安裝套件即可解決。
常見錯誤 2：找不到檔案或路徑錯誤 (No Such File or Directory)
Error in read.csv("data.csv") : cannot open file 'data.csv': No such file or directory
👉 解法： 檢查路徑中的斜線是否為正斜線 /（Windows 預設的反斜線 \ 常會導致跳脫字元報錯）。
🤖 萬用 AI 除錯提示詞 (Debug Prompt)：
當你遇到無法解決的報錯時，請複製 Console 的紅色訊息，並發送給 DeepSeek / Gemini：
「我在執行這段 R 程式碼時遇到錯誤：[貼上錯誤訊息]。請幫我檢查是缺少套件、檔案路徑錯誤還是語法問題，並請提供修正後的完整 R 程式碼與安裝指令。」
