任務情境 資料路徑與檔案結構

我們要把 Google Drive 中的家庭收支調查 Stata 檔案（inc113.dta）轉為 Excel 檔案。在轉換之前，需先讓 Colab AI / Gemini 解析編碼表（code113.doc）以了解欄位含義。

/content/drive/MyDrive/家庭收支調查/113年家庭收支調查/release/

📄 目標檔案：

  • code113.doc：欄位與變數代碼說明文件
  • inc113.dta：家庭收支原始資料檔 (Stata 格式)

AI 提示詞 給 Colab Gemini 的 Prompt 指令範本

打開 Colab 右上角的 Gemini 助手（或點擊「用 AI 撰寫程式碼」），直接複製貼上以下 Prompt： 

請幫我撰寫一段 Python 程式碼，執行以下步驟：

1. 自動掛載我的 Google Drive。
2. 切換工作目錄到：
   `/content/drive/MyDrive/家庭收支調查/113年家庭收支調查/release`
3. 使用 python-docx 套件讀取 `code113.doc` (若為舊版 doc，請處理讀取或提示；若為 docx 則提取內文)，解析並印出資料欄位說明。
4. 使用 pandas 讀取 Stata 格式資料檔 `inc113.dta`。
5. 將 `inc113.dta` 轉換並儲存為同目錄下的 `inc113.xlsx` Excel 檔案。
6. 請加上完整的套件安裝指令（如 python-docx, pandas, openpyxl）與轉檔進度印出提示。

Python 程式碼 Colab 實作程式碼 (可直接執行)

如果選擇手動建立儲存格，可以將以下程式碼貼入 Colab 執行：

步驟 1：安裝與載入必要套件

# 1. 安裝讀取 Word 檔與 Excel 轉檔所需的套件
!pip install python-docx openpyxl pandas -q

import os
import pandas as pd
from google.colab import drive

# 2. 掛載 Google Drive
drive.mount('/content/drive')

# 3. 切換至家庭收支調查 release 資料夾
target_dir = '/content/drive/MyDrive/家庭收支調查/113年家庭收支調查/release'
os.chdir(target_dir)
print(f"目前工作目錄：{os.getcwd()}")
print("資料夾檔案清單：", os.listdir('.'))

步驟 2：讀取 code113.doc 欄位定義並將 inc113.dta 轉存為 Excel

# 1. 讀取與了解欄位資訊 (處理 .doc / .docx 說明檔)
doc_path = 'code113.doc'

try:
    import docx
    doc = docx.Document(doc_path)
    print("--- code113 欄位代碼表前 10 行內文 ---")
    for p in doc.paragraphs[:10]:
        if p.text.strip():
            print(p.text)
except Exception as e:
    print(f"提示：若 {doc_path} 為舊型二進位 .doc 檔，建議先手動另存為 .docx，或直接使用 pandas 讀取 .dta 的內建欄位標籤 (labels)。")

# 2. 讀取 Stata 格式的家庭收支資料檔 (.dta)
print("\n正在讀取 inc113.dta...")
df = pd.read_stata('inc113.dta')

# 印出資料維度與欄位摘要
print(f"資料讀取完成！共 {df.shape[0]} 筆紀錄，{df.shape[1]} 個欄位。")
print("\n--- 前 5 筆資料預覽 ---")
print(df.head())

# 3. 轉存為 Excel 檔案 (.xlsx)
output_excel = 'inc113.xlsx'
print(f"\n正在將資料寫入 Excel 檔 ({output_excel})...")
df.to_excel(output_excel, index=False)
print(f"🎉 轉檔成功！已儲存至：{os.path.join(target_dir, output_excel)}")

💡 課堂教學與除錯提示 (Teacher's Note)

  • 舊版 .doc 檔案說明：主計總處提供之 code113.doc 若為舊版 Word 二進位格式，Python 的 python-docx 套件可能無法直接讀取。若遇此狀況，建議先在雲端硬碟中雙擊開啟該檔案並另存為 .docx 格式。
  • Stata 欄位標籤優勢：pd.read_stata('inc113.dta') 會自動讀取 Stata 檔案中內建的英文變數名稱與中文欄位標籤，方便同學後續進行清洗與交叉分析！
